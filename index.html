03 / OFFLINE COMMUNICATION TEST

별도 앱으로 BLE 통신 동작 테스트

별도 테스트 앱

인터넷 없이 기기끼리 메시지를 주고받는 흐름을 시험

기존에 계획했던 블루투스 메시 기능을 지도 앱에 바로 넣기 전에, 별도의 앱을 만들어 기기 발견·연결·상태 확인·메시지 중계 흐름을 테스트했습니다.

A ↔ B ↔ C
01 · 시작과 연결

권한 요청, 서비스 등록, 광고·스캔, 연결 요청과 서비스 탐색

02 · 생존 신호

주기적으로 신호를 주고받고, 일정 시간 신호가 없으면 목록에서 제거

03 · 메시지 중계

메시지 ID로 중복을 확인하고, 이미 본 메시지는 다시 중계하지 않음

04 / STARTUP & CONNECTION

테스트 흐름 ① 시작과 기기 연결

sequenceDiagram participant A as 기기 A participant B as 기기 B Note over A,B: 각자 실행: 권한 요청 → 서비스 등록 → 광고와 스캔 시작 B-->>A: 광고 (서비스 UUID + BT-ID) Note over A: 스캔으로 발견, 우리 앱 판별 A->>B: 연결 요청 (connect) A->>B: MTU 185 요청, 서비스 탐색 A->>B: 알림 구독 (subscribe) Note over A,B: B도 같은 방식으로 A에 연결 → 반대 방향 연결도 생성
1
각 기기에서 실행

권한 요청 후 서비스 등록, 광고와 스캔을 시작

2
상대 앱 발견

서비스 UUID와 Bluetooth ID를 확인해 우리 앱을 판별

3
연결 및 서비스 탐색

연결 요청 후 MTU 요청, 서비스 탐색, 알림 구독을 진행

B도 같은 방식으로 A에 연결하면 양방향 연결이 생성됩니다.
05 / HEARTBEAT & PRESENCE

테스트 흐름 ② 생존 신호와 기기 목록

sequenceDiagram participant A as 기기 A participant B as 기기 B Note over A,B: 5초마다 양쪽 모두 반복 A->>B: 생존 신호 (write) B-->>A: 쓰기 응답 (OS가 자동으로 응답) B->>A: 생존 신호 (notify) Note over A: A는 응답이나 신호를 받을 때마다 B를 살아 있음으로 갱신 rect rgb(250, 235, 215) Note over B: B 앱 종료 → 신호 끊김 end Note over A: 15초 동안 확인 없음 → 목록에서 제거
1
5초마다 반복

양쪽 기기에서 생존 신호를 주고받음

2
상태 갱신

응답이나 신호를 받을 때마다 상대 기기가 살아 있는 것으로 갱신

3
신호가 끊기면 정리

앱 종료 등으로 15초 동안 확인이 없으면 목록에서 제거

다이어그램에 표시된 주기와 제한 시간 기준으로 동작하는 테스트 흐름입니다.
06 / MESSAGE RELAY

테스트 흐름 ③ 메시지 중계와 중복 방지

sequenceDiagram participant A as 기기 A participant B as 기기 B participant C as 기기 C Note over A: A: 메시지 입력, id 부여 A->>B: 메시지 (홉 3) Note over B: B: 중복 확인 → 화면 표시 B->>C: 중계 (홉 2) Note over C: C: 중복 확인 → 화면 표시 C->>B: 중계 (홉 1) rect rgb(250, 235, 215) Note over B: B: 이미 본 id → 무시 end
1
A에서 메시지 작성

메시지에 고유 ID를 부여해 중복 여부를 확인

2
B가 수신 후 중계

처음 받은 메시지는 표시하고 다음 기기로 전달

3
이미 본 ID는 무시

메시지가 되돌아와도 중복 표시·중계를 방지

예: A → B → C로 전달된 메시지가 B에 다시 도착해도, B는 이미 본 ID이므로 무시합니다.
07 / BLE TEST RESULTS

BLE 메시지 테스트 결과

기기 A의 메시지 전송 화면, 기기 B의 기본 화면, 그리고 기기 B가 A의 메시지를 수신한 화면을 순서대로 정리했습니다.

기기 A · 테스트 메시지 전송

내 ID zi8h에서 테스트용 메시지를 보내고, 연결된 상대 기기 cvbu가 표시된 화면.

기기 B · 기본 화면

아직 메시지를 주고받기 전의 기본 화면. 연결된 기기는 0대로 표시됩니다.

기기 B · A의 메시지 수신

기기 B(cvbu)가 기기 A(zi8h)에서 보낸 “[zi8h] 테스트용 메시지”를 수신한 화면.
