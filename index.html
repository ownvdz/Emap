EMAP / API 교체 배경

작년 기준·주소만 → 매일 갱신·좌표 제공

핵심 메시지기존 생활안전지도 API는 갱신이 멈춘 주소 데이터였고, 새 API는 최신이며 좌표를 직접 제공한다.

기존

02
교체

매일 갱신되는 API이며 대부분 좌표를 직접 제공한다. 변환 호출이 대폭 줄어든다.

기존 생활안전지도 API는 좌표가 없어 주소를 지오코딩해야 했고, 데이터도 작년 기준에서 멈춰 있었습니다. 재난안전데이터공유플랫폼 API는 매일 갱신되고 대부분 좌표를 직접 제공합니다. 그래서 API를 교체했고, 이 과정에서 무더위쉼터와 한파쉼터까지 포함해 대피소를 6종으로 확장했습니다.

EMAP / 시험 실행 결과

시험 실행에서 세 가지 문제를 먼저 잡았다

핵심 메시지저장하기 전에 시험 실행(dry-run)으로 건수와 좌표를 검증해, 데이터가 조용히 사라지는 문제를 발견했다.

01
키 충돌

해일 대피장소 647건이 186건으로 줄어듦

고유값 키가 시설 번호와 장소 번호만으로 구성되어 지역이 다른데도 충돌했다. 지역 코드(ARCD)를 키에 포함해 647건을 모두 유지했다.

647 → 186 해결
02
복수 용도

무더위+한파 겸용 52,566건이 누락

응답의 구분 코드가 “1,2”처럼 쉼표로 오는 경우를 놓쳤다. 포함 여부로 판정하고 겸용 시설은 두 종류로 각각 저장해 무더위 10,134건 → 62,700건이 되었다.

52,566건 복구
03
좌표 검증

더미 230건 제외, 도·분·초 좌표 확인

민방위 응답의 시험용 더미 230건을 제외하고, 도·분·초 좌표를 서울 3곳에서 실제 위치와 대조해 변환 공식을 검증했다.

저장 전 검증
발표자 노트키보드 N으로 열기/닫기

저장하기 전에 시험 실행으로 먼저 검증했는데, 세 가지 문제가 나왔습니다. 첫째, 해일 대피장소가 647건에서 186건으로 줄었는데, 키가 지역을 구분하지 못해 충돌한 것이었고 지역 코드를 포함해 고쳤습니다. 둘째, 무더위와 한파 겸용 시설 5만 2천여 건이 빠졌습니다. 구분 코드가 쉼표로 올 수 있다는 점을 놓친 것입니다. 셋째, 시험용 더미 230건을 제외하고 도분초 좌표를 서울 세 곳에서 실제 위치와 맞춰 보았습니다. 시험 실행을 먼저 한 덕분에 잘못된 데이터를 저장하기 전에 잡았습니다.

화면이 꺼진 기기는 목록에서 사라질 수 있고, 태블릿에서 “Characteristic not found” 메시지가 뜬다. 3대 이상 멀티홉 중계는 아직 검증 전이다.

발표자 노트키보드 N으로 열기/닫기

블루투스 통합 부분입니다. 모든 기기가 같은 코드로 광고와 스캔을 동시에 하고, 서비스 UUID로 우리 앱의 기기를 찾아 자동 연결합니다. 메시지는 중복 제거와 남은 홉 수 감소로 중계합니다. 폰 두 대와 태블릿 한 대에서 메시지 전달을 확인했습니다. 다만 화면이 꺼진 기기가 목록에서 사라지는 문제와 태블릿의 전송 실패 메시지가 남아 있고, 홉 제한과 MTU 값은 측정 없이 정한 값이라 재검토가 필요합니다. 멀리 떨어진 멀티홉도 아직 검증하지 못했습니다.

EMAP / 문제 해결 과정

앱 개발에서 만난 문제 3가지와 해결

핵심 메시지빌드, 지도 인증, 블루투스 권한 문제를 각각 원인까지 확인해 해결했다.

01
빌드 오류

네이티브 라이브러리 버전 불일치

safe-area-context가 5.5.2로 설치되어 BLE 테스트 앱(5.10.1)과 달라 컴파일이 실패했다. 버전을 정확히 고정해 해결했다.

버전 고정
02
지도 인증

Android 패키지명 미등록

네이버 지도에서 인증 실패가 났고, 콘솔에 앱 패키지명(com.emap.shelter)이 등록되지 않은 것이 원인이었다. 등록 후 지도가 정상 표시된다.

해결
03
블루투스 권한

광고는 되는데 스캔 결과가 없음

새 앱에서는 위치 권한이 허용되지 않아 스캔 결과가 비었다. 위치 권한 요청을 코드에 추가했다.

해결
발표자 노트키보드 N으로 열기/닫기

앱 개발에서 겪은 문제 세 가지입니다. 첫째, 라이브러리 버전이 테스트 앱과 달라 빌드가 실패해서 버전을 정확히 고정했습니다. 둘째, 지도 인증 실패는 네이버 콘솔에 안드로이드 패키지명이 등록되지 않았던 것이 원인이었습니다. 셋째, 블루투스 스캔 결과가 비는 문제는 위치 권한이 허용되지 않은 것이었고, 코드에서 요청하도록 했습니다.

기존 mesh-core 로직 연결, 화면이 꺼진 상태에서도 동작하는 포그라운드 서비스, 멀티홉 검증을 진행한다.
