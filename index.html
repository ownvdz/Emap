같은 문제를 이미 다루는 앱이 있었다.

조사 과정에서 「안전디딤돌」이라는 공공앱이 이미 존재하는 것을 확인했고, 이후 프로젝트에서는 어떤 차별점을 만들 것인지를 중심으로 기능을 구상했습니다.

05 · CORE FEATURES

이번 앱에서 구상한 3가지

FEATURES
01

전국 비상대피소 지도

지도상에 우리나라 비상대피소 위치를 표시하고, 네이버 지도 API와 공공데이터 API를 활용해 위치 정보를 제공합니다.

02
차별점

대피소 메모 · 리뷰

대피소별 사용자 메모 및 리뷰를 작성하고 조회할 수 있도록 합니다.

03
차별점

오프라인 메시지 채팅

인터넷 사용이 어려운 비상 상황을 대비해 오프라인 메시지 채팅을 구상하며, 블루투스 메쉬 기술을 활용합니다.

지도 · 사용자 정보 · 오프라인 통신6
