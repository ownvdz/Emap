07 / PROBLEM SOLVING

문제 해결 ①: API 응답 정렬, 훈련 문자, 데이터 불일치

외부 API 데이터 이상현상 및 대피소 데이터 구조적 차이를 완목히 해결했습니다.
01 · API 일련번호 뒤죽박죽

응답 일련번호 정렬 미보장으로 최신 문자 누락 위험 -> 최대 5페이지(500건) 수신 후 일련번호 중복제거 및 최신순 재정렬 구현 완료

02 · 훈련 문자 오경보

안전한국훈련 문자로 인한 위급 팝업 혼란 -> '훈련' 키워드 포함 시 위급재난 외 팝업 제외 및 '훈련' 배지 표시 구현 완료

03 · 지진 대피장소 속성 차이

행동요령(옥외) vs DB(실내구호소) 데이터 불일치 -> 버튼명 '지진 실내구호소 보기' 구분 및 '먼저 넓은 곳 대피' 안내 병기 구현 완료

발표자 노트[N] 키로 토글

행안부 API 응답의 일련번호 정렬이 섞여 나오는 문제를 5페이지 수신 후 재정렬하여 해결했습니다. 지진 행동요령은 야외 대피를 권장하나 DB 데이터는 실내구호소이므로 버튼명을 구분했습니다.

08 / TROUBLESHOOTING CASE

DB 정지 사건 ①: 증상 및 진단 과정

운영 중 발생한 500 오류를 추적하여 Oracle Cloud DB 정지 현상을 진단했습니다.
  • 장애 증상: 어느 날 지도 탭 대피소 미표시, 브라우저 개발자 도구 확인 시 `/api/shelters` 요청 500 Internal Server Error 발생
  • 진단 과정: 화면 코드 이상 점검 -> 500 오류에 따른 Express 서버 로그 및 DB 상태 확인 -> Oracle Cloud 콘솔 접속
  • 원인 분석(추정): Oracle Cloud 콘솔에서 Autonomous DB 상태가 '정지됨'으로 확인. Autonomous DB의 7일 연속 비활동 시 자동 중지 정책 원인 추정
발표자 노트[N] 키로 토글

프로젝트 운영 중 대피소 조회가 500 오류를 내며 멈추는 장애가 발생했습니다. 클라이언트-서버-DB 순으로 점검한 결과 Oracle Cloud 콘솔에서 Autonomous DB가 '정지됨' 상태인 것을 발견했습니다.
