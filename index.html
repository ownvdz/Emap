행동요령

재난문자 부분입니다. 서버가 재난안전데이터 API를 조회해 주고, 앱 홈 화면에서 지역을 시도와 시군구까지 골라 문자를 볼 수 있습니다. 앱은 1분마다 새 문자를 확인해서 위급재난이거나, 훈련 문구가 없는 긴급재난이면 팝업을 띄웁니다. 6시간이 지난 문자는 띄우지 않습니다. 행동요령은 지진, 지진해일, 민방공, 폭염, 한파 다섯 종류를 준비했고, 그 밖의 재난은 기본 안내를 보여줍니다. 이 기능은 웹에 먼저 만들어 둔 것을 같은 기준으로 앱에 옮긴 것입니다. 원래 재난문자 탭이 따로 있었는데 홈 화면으로 합쳤습니다. 팝업의 대피장소 보기 버튼은 다음 장의 내 위치 기능으로 이어집니다.

가까운 대피소 조회가 느렸던 문제를 개선

핵심 메시지전체 행을 계산하던 쿼리를 범위 검색으로 바꾸고 위치 확인 방식도 함께 고쳐, 대기 시간을 줄였다.

가까운 대피소를 불러오는 데 21초가 걸렸습니다. 앱에서 타이머로 직접 잰 전체 시간이라 위치 확인, 서버 조회, 화면 표시가 모두 들어 있습니다. 서버 쿼리는 위도와 경도 범위 조건이 없어서 해당 종류의 모든 행, 무더위쉼터는 약 6만 건에 거리를 계산하고 정렬하는 구조였습니다. 그래서 내 위치 주변 사각형으로 먼저 거르고 그 안에서만 계산하도록 바꿨고, 3킬로미터부터 시작해 필요한 개수가 안 차면 넓힙니다. 반경 r의 원은 사각형 안에 완전히 들어가기 때문에 결과는 이전과 같습니다. 앱에서는 위치를 네트워크 위치 우선으로 구하고, 지도를 먼저 열어 기다림을 줄였습니다. 바꾼 뒤 빨라진 것은 확인했지만 쿼리와 위치 확인 중 어느 쪽이 얼마나 기여했는지는 측정하지 못했습니다. 정확한 시간은 다시 재서 보완할 예정입니다.

발표자 노트키보드 N으로 열기/닫기

폰에서 PC 없이 실행되는 앱을 만들었습니다. 개발 빌드는 PC의 개발 서버에서 코드를 받아오지만, 릴리스 빌드는 코드가 앱 안에 들어 있습니다. 서버 주소는 개발 빌드에서는 개발용 주소를, 릴리스에서는 HTTPS 도메인을 쓰도록 나눴습니다. 서버에서는 Caddy가 443 포트를 받아 API 요청은 Express로, 나머지는 웹으로 보냅니다. 지금 서명은 데모용으로 디버그 키를 썼기 때문에 실제 배포 전에는 바꿔야 합니다.

01
HTTPS 인증서

DuckDNS 레코드가 잘못된 IP를 가리킴

릴리스 앱이 서버에 연결하지 못했다. Caddy 로그에서 인증서 발급 검증이 다른 IP로 향해 실패한 것을 확인했다. 레코드를 서버 IP로 고치고 Caddy를 재시작해 해결했다.

해결
02
빌드 오류

알림 채널 설정이 라이브러리와 중복

푸시 라이브러리가 같은 설정(default_notification_channel_id)을 이미 선언해 매니페스트 병합이 실패했다. 우리 값을 쓰도록 tools:replace를 지정해 빌드가 통과했다.

해결
03
푸시 구독

안드로이드 16 휴대폰에서 토픽 구독 무응답

휴대폰 2대에서 구독이 15초 안에 응답하지 않았다. 토큰은 발급되는 것을 확인했고, 원인은 확정하지 못해 토큰 등록 방식으로 바꿨다.

이번에 만난 문제 세 가지입니다. 첫째, 릴리스 앱이 서버에 연결하지 못했는데 인증서 발급 로그를 보니 DuckDNS 레코드가 다른 IP를 가리키고 있어서 검증이 실패한 것이었습니다. 레코드를 고치고 Caddy를 다시 시작해 해결했습니다. 둘째, 푸시 라이브러리와 우리 매니페스트가 같은 설정을 선언해서 빌드가 실패했고, 우리 값을 쓰도록 지정해 해결했습니다. 셋째, 푸시의 토픽 구독이 안드로이드 16 휴대폰 두 대에서 응답하지 않았습니다. 토큰은 발급됐지만 원인은 확정하지 못했고, 다음 장에서 설명할 토큰 방식으로 바꿨습니다.

푸시 알림 구조입니다. 폰의 긴급재난문자는 통신사 방송으로 오기 때문에 일반 앱은 직접 받을 수 없습니다. 그래서 서버가 재난안전데이터 API를 60초마다 조회하고, 새 긴급재난이나 위급재난이 나오면 FCM으로 폰에 보냅니다. 앱은 켜질 때 자기 기기 토큰을 서버에 등록해 두고, 서버는 저장된 모든 토큰에 지역과 관계없이 보냅니다. 훈련 문구가 있는 긴급재난은 제외합니다. 알림을 누르면 앞에서 본 긴급 팝업이 열립니다. 서버가 지역 지정 없이 전국 문자를 조회해도 되는지와 호출량은 아직 확인하지 못했습니다.

푸시 시험 현황입니다. 처음에는 FCM 토픽 구독 방식이었습니다. 시험 전송은 서버에서 성공으로 돌아왔는데, 태블릿에만 알림이 오고 휴대폰 두 대에는 오지 않았습니다. 휴대폰에서는 토픽 구독이 15초 안에 응답하지 않았고 토큰 발급은 됐습니다. 구글 플레이 서비스를 업데이트해도 같았고 정확한 원인은 확인하지 못했습니다. 그래서 구독을 없애고, 앱이 기기 토큰을 서버에 등록하면 서버가 그 토큰으로 직접 보내는 방식으로 바꿨습니다. 서버와 앱 코드는 완성했고, 남은 확인은 세 대에서 등록, 시험 전송 수신, 앱이 꺼진 상태에서의 수신입니다. 삼성 기기는 배터리 최적화 때문에 알림이 늦을 수 있어 그것도 볼 예정입니다.
